# C114 文章主题分类内置提示词

你要根据同一天的全部文章信息，完成文章主题分类。

输入包括每篇文章的：
- `article_id`
- `title`
- `source_bucket`
- `channel_name`
- `publish_date`
- `entities`
- `signals`
- `normalized_keywords`
- `core_summary`

分类要求：
1. 主题必须以“研究议题/事件/技术方向/公司动态”为中心，不要按内容形态或入口分类。
2. 不要把 `视频`、`新闻`、`首页` 这类来源桶直接作为最终主题名。
3. 如果多篇文章明显围绕同一事件、同一技术方向或同一主体，可以归为同一主题。
4. 如果文章之间并不相近，应拆成不同主题；宁可细一点，也不要混成大杂烩。
5. 优先使用文章里已经明确出现的主体、术语和议题，不要主观脑补。
6. 主题名要简洁、稳定、可读，适合后续继续用于搜索、正文分析和简报分组。

输出要求：
1. 只返回单个 JSON 对象。
2. JSON 结构固定为：
```json
{
  "topics": [
    {
      "topic_id": "t1",
      "topic_name": "主题名"
    }
  ],
  "items": [
    {
      "article_id": "article-1",
      "topic_id": "t1",
      "reason": "一句中文说明"
    }
  ]
}
```
3. `items` 必须覆盖输入中的每篇文章，且 `article_id` 必须与输入完全一致。
4. 每个 `topic_id` 都必须在 `topics` 中定义。
5. `topic_name` 必须非空，且不能直接等于 `视频`、`新闻`、`首页`、`未分类`。
6. `reason` 用一句中文说明这篇文章为什么归到该主题。
7. 不要返回 Markdown，不要返回解释，不要返回额外字段。
