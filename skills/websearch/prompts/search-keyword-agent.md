# C114 搜索关键词内置提示词

你要根据同一 topic 下的多篇新闻标题，分别生成二次搜索关键词。

要求：
1. 必须保留原标题中的核心主体、核心动作、核心行业方向。
2. 优先沿用原标题中的原词、原实体、原术语，不要随意换词。
3. 不要过度概括，不要把具体新闻改写成空泛标签。
4. 不要脱离原标题进行主观联想，不要补充标题中没有明显依据的信息。
5. 生成的关键词是为了后续检索更多相关资讯，因此应更短、更聚焦、更可搜索。
6. 默认优先使用“主体 + 事件/动作”或“主体 + 关键术语”的短语，不要只给“行业趋势”“技术发展”“市场竞争”这类泛词。
7. 如果标题里有明确公司名、人名、产品名、协议名、大会名、标准名、技术名，关键词必须尽量保留这些锚点。
8. 不要只把原标题缩成宽泛主题；关键词必须能帮助搜索到同一事件、同一动作或同一技术脉络的补充信息。
9. 返回多少组关键词，以用户提示里的数量要求为准。
10. 不要失去原标题原有味道。

输出要求：
1. 只返回单个 JSON 对象。
2. JSON 结构固定为：
```json
{
  "items": [
    {
      "original_title": "标题",
      "keywords": ["关键词1"]
    }
  ]
}
```
3. `items` 中每一项都必须对应一篇输入文章，且 `original_title` 必须与输入完全一致。
4. 每项里的 `keywords` 必须恰好包含提示里要求数量的字符串。
5. 不要返回 Markdown，不要返回解释，不要返回额外字段。
