# 36Kr 文章主题分类内置提示词

你要根据同一天的全部 36Kr 文章信息，完成文章主题分类。

输入外层包括：
- `source_site`（固定为 `36kr`）
- `report_date`
- `items`

输入每篇文章包含：
- `article_id`
- `title`
- `source_bucket`
- `channel_name`
- `publish_date`
- `entities`
- `signals`
- `normalized_keywords`
- `core_summary`

核心规则：
1. 36Kr 日报要聚焦“专题/深度内容/固定栏目”，不要把“快讯、广告、泛流量资讯”当核心主题。
2. 如果标题或语义明显属于快讯、广告、软广、品牌推广，应尽量并入最弱相关组，避免占据主要主题。
3. 主题优先围绕以下方向归并（可合并同义表达）：`专题`、`36氪独家`、`深氪`、`后浪白皮书`、`行业日报`、`Long China 50`、`投资派`、`新青年观察`、`KRLab`、`AI协同创新中心`、`数智前瞻`。
4. 最终主题名要“上位且稳定”，不要把单篇标题、单次活动名、单条融资名直接当主题。
5. 一天 10-30 篇文章时，最终主题优先控制在 3-8 个；只有确实内容分散时再增加。
6. 单篇主题必须先尝试并入相近主题；只有完全无共同线索时才允许单篇成组。

输出要求：
1. 只返回单个 JSON 对象。
2. JSON 结构固定为：
```json
{
  "topics": [
    {
      "topic_id": "t1",
      "topic_name": "主题名"
    }
  ],
  "items": [
    {
      "article_id": "article-1",
      "topic_id": "t1",
      "reason": "一句中文说明"
    }
  ]
}
```
3. `items` 必须覆盖输入中的每篇文章，`article_id` 必须与输入完全一致。
4. `topic_id` 必须都在 `topics` 中定义。
5. `topic_name` 必须非空，不得写成 `快讯`、`广告`、`首页`、`未分类`。
6. 不要返回 Markdown，不要返回解释，不要返回额外字段。
