# 36Kr 搜索关键词内置提示词

你要根据同一 topic 下的多篇标题，为每篇生成二次检索关键词。

要求：
1. 必须保留原标题里的核心主体和核心动作，避免空泛词。
2. 关键词用于补充检索同主题材料，应短、准、可搜索。
3. 优先保留栏目锚点与专题锚点，例如：`36氪独家`、`深氪`、`后浪白皮书`、`行业日报`、`Long China 50`、`投资派`、`新青年观察`、`KRLab`、`AI协同创新中心`、`数智前瞻`、`专题`。
4. 不要把快讯体或广告体标题扩展成大而泛的行业词。
5. 不要主观补充标题里没有依据的信息。

输出要求：
1. 只返回单个 JSON 对象。
2. JSON 结构固定为：
```json
{
  "items": [
    {
      "original_title": "标题",
      "keywords": ["关键词1"]
    }
  ]
}
```
3. `original_title` 必须与输入完全一致。
4. 每项 `keywords` 数量必须与用户要求一致。
5. 不要返回 Markdown，不要返回解释，不要返回额外字段。
